# 괴물 사진사: 미지의 숲

기존 `game-plan.md`, `game-design.md`와 프로젝트에 준비된 PNG·MP3 리소스를 바탕으로 구현한 순수 HTML/CSS/JavaScript 게임입니다. 외부 라이브러리, 빌드, 계정, 서버 API가 필요하지 않습니다.

## 실행

1. 프로젝트의 `index.html`을 Edge 또는 Chrome에서 엽니다.
2. 이미지 로딩이 끝나면 **숲으로 들어가기**를 누릅니다.
3. 조작 안내 → 첫 탐사 준비 → 탐사 시작 순서로 진행합니다.

마우스가 있는 PC와 960×540 이상 화면을 권장합니다. 768px 미만에서는 메뉴·도감만 이용할 수 있으며 PC/가로 화면 안내를 표시합니다.

브라우저가 `file://` 사진 내보내기를 제한하면 Canvas 미리보기로 대체합니다. 개발용 로컬 서버를 사용할 수도 있습니다. Python이 설치되어 있다면 프로젝트 폴더에서 다음 명령을 실행하고 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 프레임과 카메라 이동 |
| 왼쪽 클릭 | 촬영, 필름 1장 사용 |
| 우클릭 유지 | 중앙 조준 및 월드 확대 |
| 마우스 휠 | 줌 단계 선택: 1 / 1.25 / 1.6 / 2 |
| R | 필름 재장전 (기본 2초) |
| ESC / 일시정지 버튼 | 정지·재개 |

두 눈이 바깥 프레임에 들어오면 성공, 작은 중앙 영역에 모두 들어오면 완벽한 사진입니다. 한쪽 눈이 가려진 동안은 실패합니다. 프레임이 초록색이면 촬영 가능한 상태입니다. 안개 유령은 우클릭 조준 중 1.6배 이상 확대해야 촬영할 수 있습니다.

## 구현 범위

- 시작, 도움말, 라운드 안내, 플레이, 일시정지, 앨범, 사진 상세, 상점, 최종 결과, 도감
- 괴물 5종의 서로 다른 노출 시간과 이동 행동, 실제 PNG 기준 눈 좌표
- 라운드별 10마리, 모든 라운드 60초, 동시 출현 1/1/2/2/3마리
- 가중치 기반 등장, 놓친 괴물의 3~6초 후 재등장, 2회 놓치면 노출 시간 20% 보정
- 5라운드 안개 유령 최소 1마리, 각 라운드 최대 2마리
- 필름·재장전, 촬영 잠금, 양쪽 눈 판정, 가장 가까운 한 마리만 촬영
- 코인·완벽 사진 1.5배·라운드 보너스·실패 사진 평가 감점
- 작은 Canvas 촬영 이미지와 성공/실패 앨범, BEST 사진
- 장비 4종의 가격·최대 단계·실제 효과, 재도전 시 코인·장비 유지
- 이미지·사운드, 소멸 입자, 섬광 설정
- 최고 기록·등급·발견한 괴물·음악/효과음/섬광 설정 저장
- 창 포커스 이탈·탭 숨김 시 자동 일시정지, 손상된 저장 데이터 복구

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 공통 화면과 스크립트 연결 |
| `css/style.css` | 숲 레이어, 화면, HUD, 반응형 메뉴 |
| `js/config.js` | 괴물·눈 좌표·라운드·장비 수치 |
| `js/engine.js` | DOM과 독립된 게임 상태·촬영·라운드·구매 규칙 |
| `js/main.js` | 화면 전환·입력·렌더링·사진 생성·게임 루프 |
| `js/storage.js` | 기록과 설정 저장·검증 |
| `js/audio.js` | 음악·효과음 제어 |
| `tests/engine.test.cjs` | 핵심 규칙 회귀 테스트 |

설계서에서 허용한 점진적 파일 분리 방식을 따라 UI 기능은 `main.js`에 모았습니다. 일반 script 태그를 사용하므로 로컬 파일에서도 모듈 서버 없이 실행할 수 있습니다.

## 구현 중 정한 세부 기준

- 실제 전경 폴더명 `assets/images/foregrouds`를 그대로 사용합니다. 기존 파일을 이동하거나 변경하지 않았습니다.
- 촬영 프레임은 정확한 판정 범위를 보여주기 위해 CSS로 그립니다. 나머지 게임 이미지와 장비·앨범 UI에는 제공된 리소스를 사용합니다.
- 최종 등급 기준은 기획서에 수치가 없어 완벽 사진/성공 사진 비율로 정했습니다: S 80% 이상, A 50% 이상, B 25% 이상, 나머지 C.
- 최고 코인은 장비 구매에 쓴 금액도 포함한 총 획득 코인입니다. 최고 기록과 등급은 5라운드 완료 시 갱신합니다.
- 도감은 발견 여부를 저장하며, 실제 사진은 메모리에만 보관합니다. 새로고침하면 현재 탐사와 사진은 초기화됩니다.
- 전경 가지는 화면 가장자리에 배치하고 한쪽 눈 노출은 별도 가림 요소로 처리하여 보이는 상태와 판정을 맞춥니다.

## 검증

Node.js가 있는 환경에서 실행합니다. 게임 실행 자체에는 Node.js가 필요하지 않습니다.

```sh
node tests/engine.test.cjs
```

- 빈 사진·중복 사진·촬영 잠금·가장 가까운 개체 선택

- 유령 줌 조건·좌표 변환

JavaScript 문법과 리소스 파일 존재 여부도 검사했습니다.

**남은 확인:** 실제 브라우저 렌더링, 마우스 추적감, 눈 판정 체감, 사운드 청취, 60초 라운드 플레이 밸런스, 화면 크기별 시각 QA, GitHub Pages 실행. 개발 환경이 브라우저 프로세스 실행과 로컬 파일 URL 열기를 차단하여 실제 브라우저 검증을 완료하지 못했습니다. 로직 테스트 통과가 실제 플레이 검증을 대신하지는 않습니다.

## 배포

상대 경로와 `.nojekyll`을 사용합니다. GitHub Pages에 게시할 수 있는 정적 파일 구성이며 이번 작업에서 원격 저장소 push나 공개 배포는 수행하지 않았습니다.


## 추가 적용 규칙

- 괴물은 개체별로 기본 크기의 70~130% 크기로 생성됩니다. 가로세로 비율과 눈 판정도 함께 바뀌며, 같은 개체의 재등장 크기는 유지합니다.
- 모든 라운드 제한 시간은 60초입니다.
- 실패 사진은 라운드마다 3장까지 허용합니다. 4번째 실패 사진을 찍으면 즉시 라운드 실패로 종료됩니다. 실패 사진 수는 HUD에서 확인할 수 있습니다.
- 상점의 현재 보유 코인을 강조 표시하며 장비 구매 직후 잔액을 갱신합니다.
- 추가 검증: `node tests/rules.test.cjs` (60초 종료, 4번째 실패, 랜덤 크기와 눈 판정, 상점 잔액 표시).

## 이동 패턴 업데이트

- 기본 이동 속도(월드 좌표 px/초): 이끼뿔 80, 달빛토끼 170, 두눈 흉내쟁이 250, 그림자 늑대 350, 안개 유령 420.
- 다음 라운드마다 기본 속도의 8%씩 추가합니다. 5라운드는 기본 속도의 132%입니다.
- 시작 위치 주변의 좁은 왕복 대신 숲 좌우 가장자리까지 이동하고 반사하듯 방향을 바꿉니다. 토끼의 뜀과 유령의 위아래 부유는 유지합니다.
- 유령은 두 눈을 드러낸 뒤 약 1.1초 후 0.55초간 사라지고 반대쪽 영역의 다른 높이에서 다시 나타납니다. 한 번의 등장마다 한 번 순간이동하며 크기와 개체는 유지합니다.
- 순간이동 중에는 화면·앨범에 그리지 않으며 촬영할 수 없습니다. 동시 출현 슬롯은 유지하고, 일시정지 중에는 순간이동 대기도 멈춥니다.
- `node tests/movement.test.cjs`: 속도 차이, 넓은 이동 범위, 경계 반사, 프레임 독립 이동, 유령 비노출·재등장·촬영·일시정지·출현 수 테스트 통과. 실제 브라우저에서의 속도 체감은 별도 확인이 필요합니다.
